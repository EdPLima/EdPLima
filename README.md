# Eduardo Pereira

### Data Scientist | Machine Learning Engineer

Data Scientist with **3+ years of experience in Data & AI**, focused on building machine learning solutions for real-world business problems, particularly in the **financial sector, credit risk, and fraud detection**.

Experienced across the **end-to-end machine learning lifecycle**, from data analysis, statistical modeling, and feature engineering to model deployment, monitoring, and retraining. I have worked with highly imbalanced classification problems, large-scale data processing, time series, and production-oriented ML systems.

My technical stack includes **Python, SQL, Pandas, Scikit-learn, LightGBM, XGBoost, PySpark, Databricks, MLflow, Docker, Airflow, PostgreSQL, and Power BI**, with experience applying MLOps practices such as experiment tracking, model registry, CI/CD, model monitoring, and automated retraining.

I also work with **Generative AI and RAG applications**, integrating LLMs, embeddings, vector databases, and retrieval pipelines to build AI-powered solutions.
