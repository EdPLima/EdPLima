# 👨‍💻 Eduardo Pereira  
**Cientista de Dados**

Atuo como cientista de dados com foco em aplicações no setor financeiro, especialmente em detecção de fraude e modelagem de risco. Tenho experiência no desenvolvimento de soluções orientadas a dados, cobrindo todo o ciclo analítico: definição do problema, engenharia de atributos, modelagem, avaliação e interpretação dos resultados.

Neste repositório, apresento projetos estruturados com foco em problemas reais de negócio, incluindo credit scoring e prevenção a fraudes, utilizando boas práticas de modelagem, validação e monitoramento.
